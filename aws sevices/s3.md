. What is Amazon S3 and what are its key features?
Answer:
Amazon S3 (Simple Storage Service) is an object storage service that provides:
Scalability: Store unlimited data.
Durability: 99.999999999% (11 9s) durability.
Availability: Multiple storage classes for different SLAs.{service level argeement}
Data Access Control via IAM, Bucket Policies, ACLs.{acess control list}
Versioning, encryption, lifecycle rules, event notifications, etc.

. What is the difference between S3 and EBS?

| Feature     | S3                     | EBS                          |
| ----------- | ---------------------- | ---------------------------- |
| Type        | Object storage         | Block storage                |
| Access      | HTTP/HTTPS (API-based) | Attached to EC2 instances    |
| Use case    | Backups, static files  | Boot volumes, databases      |
| Scalability | Virtually unlimited    | Limited to 64 TiB per volume |

5.What is Versioning in S3?
Answer:

Allows you to preserve, retrieve, and restore every version of every object.

Prevents accidental overwrites or deletions.

When enabled, a delete operation marks the object as deleted with a delete marker.

6. What is the difference between Bucket Policy and IAM Policy?
Answer:

Bucket Policy: Applies to the bucket and objects, supports cross-account access.
IAM Policy: Applies to users, roles, or groups within the same account.
Use bucket policies for external access, IAM policies for internal users.

7. What is the S3 Lifecycle Policy?
Answer:
Used to automate transitions between storage classes and expire/delete objects.

Examples:

Move to S3 Standard-IA after 30 days.
Delete after 365 days.
Archive to Glacier after 90 days.

8. 8. How do you host a static website on S3?
Answer:

Enable static website hosting in the bucket settings.
Upload your index.html and error.html.
Set public read permissions (if not using CloudFront).
Use the S3 website endpoint URL to access it.




9. What is S3 Event Notification?
Answer:

Triggers when certain events happen (e.g., s3:ObjectCreated:*).

Can send events to:

SNS Topic

SQS Queue

Lambda Function

Common use cases: Image processing, auditing, ETL.

10. What are S3 Access Points?
Answer:

A way to manage access to shared data in S3 at scale.
Each access point has its own:
Name
Policy
VPC restriction (optional)
